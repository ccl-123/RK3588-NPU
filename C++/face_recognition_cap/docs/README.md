## 🎯 按角色查找文档

### 最终用户

如果您是系统的使用者，建议按以下顺序阅读：

1. **[快速开始](快速开始.md)** - 了解如何启动系统
2. **[用户使用手册](用户使用手册.md)** - 学习如何使用各项功能

### 系统管理员

如果您负责系统的部署和维护，建议阅读：

1. **[快速开始](快速开始.md)** - 系统安装和配置
2. **[数据库集成说明](数据库集成说明.md)** - 数据库管理
3. **[用户使用手册](用户使用手册.md)** - 故障排除

### 开发者

如果您需要扩展或修改系统，建议阅读：

1. **[模块说明](模块说明.md)** - 理解系统架构
2. **[开发者文档](开发者文档.md)** - 开发环境和 API
3. **[API 文档](API文档.md)** - 详细接口说明
4. **[数据库集成说明](数据库集成说明.md)** - 数据库设计

### 项目经理

如果您负责项目管理，建议阅读：

1. **[GUI 完整产品总结](GUI完整产品总结.md)** - 了解当前功能
2. **[后续开发工作规划](后续开发工作规划.md)** - 规划未来工作
