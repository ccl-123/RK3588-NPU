## 📅 版本演进

### V1.0 (2025-11)
- 实现基础 RetinaFace 检测与 FaceNet 识别。
- 初步建立三线程流水线。
- 引入基础 SQLite 存储。

### V2.0
- **架构升级**: 优化为四级并行流水线，引入零拷贝数据流。
- **UI 重构**: 基于 Qt5 开发全新的侧边导航式现代化界面。
- **业务完善**: 增加自动考勤判断、节假日/新闻/天气服务集成，新增 **LLM 智能分析 Agent**。
- **健壮性**: 实现摄像头热插拔自动恢复与热重载。

### V2.2 (当前版本)
- **ReAct Agent 框架**: 实现完整的 Reasoning-Acting 循环，支持工具调用。
- **Agent 工具系统**: 内置考勤查询、用户查询、系统信息、计算器、帮助等工具。
- **目录重构**: 解耦 GUI 服务和工具类到主项目目录 (`gui_services/`, `gui_utils/`)。
- **RAG 模块**: 实验性检索增强生成支持（默认禁用）。
- **文档完善**: 新增 Agent 模块说明文档。
