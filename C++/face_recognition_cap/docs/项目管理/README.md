## 📈 项目概况

### 基本信息
- **项目名称**: 人脸识别考勤系统
- **当前版本**: v2.0
- **开发语言**: C++
- **UI框架**: Qt Widgets
- **开发周期**: 持续开发

### 核心功能
- ✅ 人脸检测与识别
- ✅ 用户管理
- ✅ 考勤打卡
- ✅ 数据查询与导出
- ✅ 系统设置
- ✅ 音频提示
- ✅ 深色/浅色主题

### 技术特点
- 🎯 高准确度识别（FaceNet）
- ⚡ 快速响应（< 500ms）
- 🎨 现代化UI设计
- 💾 SQLite数据库
- 🔊 音频反馈系统
- 🌓 主题切换
