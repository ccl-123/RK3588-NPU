# GUI 完整产品总结

## 🎯 产品定位
一款基于 RK3588 NPU 深度优化的工业级高性能人脸识别考勤终端。

## ✨ 已实现的核心功能

### 1. 算法与流水线
- **四级流水线并行**: 实现了采集、前处理、检测、识别与后处理的完全异步并行，端到端延迟控制在 35ms 以内。
- **Zero-Copy 架构**: 全链路应用 V4L2 mmap 映射与 `std::shared_ptr` 引用计数浅拷贝，消除了像素数据的中间拷贝。
- **硬件全卸载**: 缩放（RGA）、检测（NPU）、识别（NPU）全部由硬件单元完成，CPU 负载极低。

### 2. 数据库与业务
- **SQLite DAO 体系**: 结构化的 DAO 模式，支持人员信息与特征向量的本地持久化。
- **弹性规则引擎**: 支持配置上班/下班时间，自动判定“正常/迟到/早退”状态。
- **动态特征管理**: 支持运行时注册、热重载特征库，无需重启应用。

### 3. UI/UX 现代化
- **主题化设计**: 基于 Qt5 自定义 QSS，支持深色/浅色模式无缝切换。
- **服务集成**: 内置天气、新闻、节假日实时资讯服务。
- **SVG 图标化**: 全面采用矢量图标，支持高分辨率屏幕。

## 📊 性能数据总结 (RK3588)
- **图像分辨率**: 1920x1080 (采集) -> 640x640 (检测输入)。
- **吞吐量**: 稳定 35-45 FPS。
- **识别准确率**: Top-1 匹配相似度阈值 0.5 时，准确率 > 98%（基于测试集）。
