# GUI 完整产品总结

> 版本: v2.4
> 更新日期: 2026-04-01

## 产品定位

一款基于 RK3588 NPU 的人脸识别考勤终端，并内置端云双模式 AI Agent。

## 已实现能力

### 1. 识别主链路

- V4L2 + mmap 零拷贝采集
- RGA 图像加速
- RKNN NPU 检测与识别
- 多线程流水线

### 2. 业务层

- SQLite 本地持久化
- 用户管理
- 自动签到 / 签退
- 正常 / 迟到 / 早退判定

### 3. GUI

- Qt5 现代界面
- 智能看板
- 考勤记录
- 用户管理
- 设置页

### 4. AI Agent

当前已支持：

- 本地 RKLLM
- OpenAI 兼容远端接口

当前工具集已支持：

- 全局考勤分析
- 单员工考勤分析
- 部门考勤分析
- 排名分析
- 缺卡缺勤分析

## 当前用户最有价值的能力

用户已经可以直接问：

- “今天谁迟到了？”
- “张三这周出勤怎么样？”
- “研发部今天出勤率多少？”
- “本月迟到最多的是谁？”
- “今天谁还没签到？”

这已经从“报表系统”升级成了“问答式考勤助手”。
