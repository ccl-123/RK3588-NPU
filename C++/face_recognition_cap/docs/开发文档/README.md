## 🏗️ 技术栈

### 核心技术
- **语言**: C++17
- **UI框架**: Qt 5.15
- **数据库**: SQLite
- **AI模型**: RetinaFace + FaceNet
- **日志**: spdlog

### 构建工具
- **CMake**: 3.10+
- **编译器**: GCC 7.5+ / MSVC 2019+
