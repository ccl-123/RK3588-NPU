## 当前实现重点

当前代码状态已经和早期文档有明显差异，主要体现在：

- 远端路径使用 OpenAI 兼容接口
- Agent 工具集从早期 5 个扩展到了 9 个
- 工具结果采用结构化消息，不再只是旧式纯文本拼接
- 对话记忆按最近用户轮次保留，避免工具消息打断半轮上下文
