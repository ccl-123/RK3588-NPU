## 核心模块

### 1. FaceRecognitionApp

**文件**: `include/app/face_recognition_app.h`

**职责**: 人脸识别应用主类，协调各模块工作

**关键方法**:

```cpp
// 初始化
int initialize(const AppConfig& config);

// 运行主循环（命令行模式）
void run();

// GUI 模式：获取当前帧
bool get_current_frame(cv::Mat& frame);

// GUI 模式：处理单帧
bool process_single_frame(cv::Mat& frame, 
                         std::vector<RecognitionResult>& results);

// 设置识别回调
void set_recognition_callback(RecognitionCallback callback);
```

**使用示例**:

```cpp
// 创建应用
FaceRecognitionApp app;

// 配置
AppConfig config;
config.retinaface_model_path = "model/retinaface.rknn";
config.facenet_model_path = "model/w600k_mbf.rknn";
config.camera_type = "usb";
config.device_number = "21";
config.database_path = "data.db";
config.use_database = true;

// 初始化
if (app.initialize(config) != 0) {
    return -1;
}

// 设置回调
app.set_recognition_callback([](int user_id, const std::string& name, float similarity) {
    std::cout << "Recognized: " << name << std::endl;
});

// 运行
app.run();
```

## API 参考

### 数据结构

#### AppConfig

```cpp
struct AppConfig {
    std::string retinaface_model_path;  // RetinaFace 模型路径
    std::string facenet_model_path;     // FaceNet 模型路径
    std::string camera_type;            // "usb" 或 "mipi"
    std::string device_number;          // 设备编号
    std::string database_path;          // 数据库路径
    bool use_database;                  // 是否使用数据库
    int camera_width;                   // 摄像头宽度
    int camera_height;                  // 摄像头高度
    float box_conf_threshold;           // 检测置信度阈值
    float nms_threshold;                // NMS 阈值
    float facenet_threshold;            // 识别阈值
    bool use_async_usb;                 // 异步 USB 读取
    int perf_report_interval;           // 性能报告间隔
};
```

#### RecognitionResult

```cpp
struct RecognitionResult {
    int user_id;                        // 用户 ID（-1 表示未识别）
    std::string user_name;              // 用户姓名
    float similarity;                   // 相似度
    cv::Rect face_box;                  // 人脸框
    std::vector<cv::Point2f> landmarks; // 关键点
};
```

#### UserInfo

```cpp
namespace db {
struct UserInfo {
    int user_id;
    std::string user_name;
    std::string employee_id;
    std::string department;
    std::string position;
    std::string phone;
    std::string email;
    int status;                         // 1=启用, 0=禁用
    std::time_t created_at;
    std::time_t updated_at;
};
}
```

#### AttendanceRecord

```cpp
namespace db {
struct AttendanceRecord {
    int record_id;
    int user_id;
    std::string user_name;
    std::time_t check_time;
    AttendanceType type;                // CHECK_IN 或 CHECK_OUT
    std::string location;
    float temperature;
};
}
```

### 回调函数

#### RecognitionCallback

```cpp
using RecognitionCallback = std::function<void(
    int user_id,
    const std::string& user_name,
    float similarity
)>;
```

**使用示例**:

```cpp
app.set_recognition_callback([](int user_id, const std::string& name, float sim) {
    if (user_id > 0) {
        std::cout << "Welcome, " << name << "!" << std::endl;
    } else {
        std::cout << "Unknown person" << std::endl;
    }
});
```

4. **代码风格**: 遵循 Google C++ Style Guide
