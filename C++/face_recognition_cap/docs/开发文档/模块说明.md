# 模块说明

> 版本: v2.4
> 更新日期: 2026-04-01

本文档说明当前项目各模块职责，以及最近新增 Agent 工具后的分层关系。

## 系统分层

```text
Main / GUI
  ↓
GUI Services
  ↓
Agent / Service
  ↓
Database / App / Core / Hardware
```

## 1. GUI 层

主要位于：

- `gui/src/`
- `gui/include/`

职责：

- 页面与组件渲染
- 用户交互
- 展示 AI 流式输出
- 展示工具调用、工具结果、思考状态

关键页面：

- `recognition_page`
- `dashboard_page`
- `attendance_page`
- `user_management_page`
- `settings_page`

## 2. GUI Services 层

主要位于：

- `include/gui_services/`
- `src/gui_services/`

职责：

- 把 GUI 与业务 / Agent 解耦
- 管理本地 / 远端 AI 生命周期
- 聚合天气、新闻、节假日等看板服务

关键服务：

- `AiAnalysisService`
  远端 AI 服务，支持 OpenAI 兼容接口
- `LocalAiAnalysisService`
  本地 RKLLM 服务
- `AiPromptBuilder`
  普通分析模式提示词组装
- `LlmProtocolAdapter`
  统一解析不同远端 SSE 协议

## 3. Agent 层

主要位于：

- `include/agent/`
- `src/agent/`

职责：

- 执行 ReAct 循环
- 管理工具注册与执行
- 管理对话记忆
- 管理增量 answer / reasoning 解析

关键组件：

- `ReactAgent`
- `AgentService`
- `ToolRegistry`
- `ToolExecutor`
- `ConversationMemory`
- `IncrementalResponseParser`

## 4. Tools 层

主要位于：

- `include/tools/`
- `src/tools/`

当前内置工具：

- `query_attendance`
- `lookup_user_attendance`
- `lookup_department_attendance`
- `lookup_attendance_ranking`
- `lookup_missing_attendance`
- `query_user`
- `system_info`
- `help`
- `calculator`

这些工具是当前 Agent 的业务能力核心，也是最近最需要保持文档与代码同步的部分。

## 5. Service 层

主要位于：

- `include/service/`
- `src/service/`

职责：

- 封装考勤业务与用户业务
- 对 DAO 层提供更稳定的业务接口

核心类：

- `AttendanceService`
- `UserService`

当前新增工具并没有直接写 SQL，而是优先复用这层能力，例如：

- 单员工考勤工具复用 `query_user_records`
- 部门、排行、缺卡工具复用 `get_all_users` 与 `query_records_range`

## 6. Database 层

主要位于：

- `include/database/`
- `src/database/`

职责：

- 负责 DAO 实现
- 提供数据库类型定义
- 管理 SQLite 连接与 SQL 执行

常用 DAO：

- `AttendanceRecordDAO`
- `UserDAO`
- `FaceFeatureDAO`

## 7. App 层

主要位于：

- `include/app/`
- `src/app/`

职责：

- 人脸识别主链路编排
- 管理多线程流水线
- 管理 RKNN / RKLLM 模型生命周期

关键类：

- `FaceRecognitionApp`
- `ModelManager`
- `FeatureLibrary`
- `LocalLLMThread`

## 8. Core / Hardware 层

Core 层职责：

- YOLOv8-face 检测
- FaceNet 特征提取
- 后处理与相似度计算

Hardware 层职责：

- V4L2 采集
- RGA 加速
- RKNN / RKLLM 运行时依赖

## 最近模块变化重点

最近一轮改动里，模块层面最值得注意的是：

1. 远端 Agent 使用 OpenAI 兼容接口
2. Agent 工具集从早期基础工具扩展到了个人、部门、排行、缺卡分析
3. 工具执行结果改成结构化观察块，不再只是旧式纯文本包装
4. 对话记忆与 reasoning 标签解析已按当前 Agent 行为修正

## 开发注意

如果后续继续增强 Agent 工具，不要只改 `src/tools/`：

- 工具注册
- PromptTemplates
- HelpTool
- 文档
- README

都需要同步更新。
