## 🎯 功能概述

数据库集成为人脸识别系统提供以下功能：

### 核心功能
- ✅ **用户管理**: 用户信息的增删改查
- ✅ **特征库管理**: 从数据库加载人脸特征，支持动态更新
- ✅ **考勤记录**: 自动记录识别结果，支持重复打卡检测
- ✅ **考勤统计**: 日报、月报、迟到早退统计
- ✅ **数据持久化**: SQLite 数据库，零配置，单文件存储

### 技术特性
- 🚀 **高性能**: 单例模式 + 预处理语句，识别性能无影响
- 🔒 **线程安全**: Mutex 保护，支持多线程访问
- 📦 **轻量级**: SQLite 嵌入式数据库，无需额外服务
- 🔄 **兼容性**: 同时支持文件系统模式和数据库模式

## 🏗️ 系统架构

### 六层架构

```
┌─────────────────────────────────────────┐
│          GUI 层 (未实现)                 │
├─────────────────────────────────────────┤
│          Service 层                      │
│  - AttendanceService (考勤业务)          │
│  - UserService (用户管理)                │
├─────────────────────────────────────────┤
│          Database 层                     │
│  - DatabaseManager (连接管理)            │
│  - UserDAO (用户数据访问)                │
│  - FaceFeatureDAO (特征数据访问)         │
│  - AttendanceRecordDAO (考勤数据访问)    │
├─────────────────────────────────────────┤
│          App 层                          │
│  - FaceRecognitionApp (主应用)           │
│  - FeatureLibrary (特征库)               │
│  - ModelManager (模型管理)               │
├─────────────────────────────────────────┤
│          Core 层                         │
│  - RetinaFace (人脸检测)                 │
│  - FaceNet (特征提取)                    │
├─────────────────────────────────────────┤
│          Hardware 层                     │
│  - CameraUtil (摄像头)                   │
│  - RGA (硬件加速)                        │
└─────────────────────────────────────────┘
```

### 数据流向

```
摄像头 → 人脸检测 → 特征提取 → 特征匹配 → 识别结果
                                    ↓
                              回调函数
                                    ↓
                          AttendanceService
                                    ↓
                          保存到数据库
```

## 💾 数据库设计

### 表结构

#### 1. users (用户表)
| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | INTEGER | 主键，自增 |
| user_name | VARCHAR(50) | 用户姓名，唯一 |
| employee_id | VARCHAR(50) | 工号 |
| department | VARCHAR(100) | 部门 |
| position | VARCHAR(100) | 职位 |
| phone | VARCHAR(20) | 电话 |
| email | VARCHAR(100) | 邮箱 |
| photo_path | VARCHAR(255) | 照片路径 |
| status | INTEGER | 状态(0=禁用, 1=启用) |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

#### 2. face_features (人脸特征表)
| 字段 | 类型 | 说明 |
|------|------|------|
| feature_id | INTEGER | 主键，自增 |
| user_id | INTEGER | 用户ID，外键 |
| feature_vector | BLOB | 512维特征向量(2048字节) |
| feature_quality | REAL | 特征质量 |
| source_image | VARCHAR(255) | 源图像路径 |
| created_at | DATETIME | 创建时间 |

#### 3. attendance_records (考勤记录表)
| 字段 | 类型 | 说明 |
|------|------|------|
| record_id | INTEGER | 主键，自增 |
| user_id | INTEGER | 用户ID |
| user_name | VARCHAR(50) | 用户姓名 |
| check_time | DATETIME | 打卡时间 |
| check_type | INTEGER | 类型(1=签到, 2=签退) |
| similarity | REAL | 相似度 |
| face_image | VARCHAR(255) | 人脸图像路径 |
| device_id | VARCHAR(50) | 设备ID |
| location | VARCHAR(100) | 位置 |
| status | INTEGER | 状态(1=正常, 2=迟到, 3=早退) |
| remark | TEXT | 备注 |

## 🚀 快速开始

### 1. 编译项目

```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition_cap
bash build.sh
```

### 2. 初始化数据库

```bash
cd install/face_recognition_cap
./db_tool init data/database/face_recognition.db
```

### 3. 添加用户

```bash
./db_tool add_user data/database/face_recognition.db "xu" "技术部"
./db_tool add_user data/database/face_recognition.db "lin" "市场部"
./db_tool add_user data/database/face_recognition.db "chenliang" "研发部"
```

### 4. 提取人脸特征

使用 `face_recognition` 项目提取特征：

```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition/install/face_recognition
./face_recognition data/model/retinaface.rknn data/model/w600k_mbf.rknn 1
```

这会从 `data/img/` 目录读取所有图片并提取特征到 `data/face_feature_lib/`。

### 5. 复制特征文件

```bash
mkdir -p /home/firefly/open_project/edge2-npu/C++/face_recognition_cap/install/face_recognition_cap/data/feature
cp /home/firefly/open_project/edge2-npu/C++/face_recognition/install/face_recognition/data/face_feature_lib/*.dat \
   /home/firefly/open_project/edge2-npu/C++/face_recognition_cap/install/face_recognition_cap/data/feature/
```

### 6. 导入特征到数据库

```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition_cap/install/face_recognition_cap
./db_tool import_features data/database/face_recognition.db data/feature
```

### 7. 查看用户列表和统计

```bash
./db_tool list_users data/database/face_recognition.db
./db_tool stats data/database/face_recognition.db
```

### 8. 运行人脸识别(数据库模式)

```bash
./face_recognition_cap data/model/retinaface.rknn data/model/w600k_mbf.rknn usb 21 --db
```

### 9. 查看考勤统计

```bash
./db_tool attendance data/database/face_recognition.db 2025-11-20
```

## 📚 API使用

### AttendanceService (考勤服务)

```cpp
#include "service/attendance_service.h"

// 创建服务
auto db_manager = db::DatabaseManager::instance();
service::AttendanceService attendance_service(db_manager);

// 记录考勤
int record_id = attendance_service.record_attendance(
    user_id,        // 用户ID
    "xu",           // 用户姓名
    0.85,           // 相似度
    "",             // 人脸图像路径(可选)
    1               // 打卡类型(1=签到)
);

// 查询考勤记录
auto records = attendance_service.query_records_by_date("2025-11-20");

// 获取统计
auto stats = attendance_service.get_statistics("2025-11-20");
std::cout << "Total: " << stats.total_count << std::endl;
std::cout << "Late: " << stats.late_count << std::endl;
```

### UserService (用户服务)

```cpp
#include "service/user_service.h"

// 创建服务
service::UserService user_service(db_manager, &feature_library);

// 注册用户
auto result = user_service.register_user("xu", "001", "技术部");
if (result.success) {
    std::cout << "User ID: " << result.user_id << std::endl;
}

// 添加人脸特征
std::vector<float> feature_vector(512);  // 512维特征
int feature_id = user_service.add_face_feature(user_id, feature_vector);

// 查询所有用户
auto users = user_service.get_all_users();
```

## ⚡ 性能优化

### 数据库性能

- **索引优化**: 为高频查询字段建立索引
  - `user_id`, `check_time`, `DATE(check_time)`
- **预处理语句**: 避免SQL注入，提升性能
- **事务批处理**: 批量操作使用事务

### 识别性能

数据库模式对识别性能的影响：

| 操作 | 文件模式 | 数据库模式 | 影响 |
|------|---------|-----------|------|
| 特征库加载 | ~50ms | ~100ms | 启动时一次性 |
| 特征匹配 | 0.5ms | 0.5ms | 无影响 |
| 考勤记录 | N/A | 1-2ms | 异步回调 |
| 总FPS | 60-73 | 60-73 | 无影响 |

**结论**: 数据库集成对实时识别性能无影响，考勤记录通过回调异步处理。

## 🔧 故障排查

### Q1: 数据库初始化失败

**解决方法**:
```bash
# 检查目录权限
mkdir -p data/database
chmod 755 data/database

# 重新初始化
./db_tool init data/database/face_recognition.db
```

### Q2: 特征库加载失败

**解决方法**:
```bash
# 检查数据库中是否有用户和特征
./db_tool stats data/database/face_recognition.db

# 如果没有，先添加用户和特征
```

### Q3: 考勤记录未保存

**可能原因**:
- 未启用数据库模式(缺少 `--db` 参数)
- 重复打卡被过滤(5分钟内)
- 数据库权限问题
