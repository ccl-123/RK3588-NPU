## 3. 烧录系统到 SD 卡

### 3.1 官方烧录教程

请参考 **Firefly 官方 Wiki** 的详细教程进行 SD 卡系统烧录：

> 📖 **官方教程链接**：https://wiki.t-firefly.com/zh_CN/iCore-3588Q/upgrade_firmware_sd.html

### 3.2 烧录步骤概要

1. 从 [Firefly 资料下载页](https://www.t-firefly.com/doc/download/202.html) 下载：
   - **SD_Firmware_Tool**（SD 卡烧录工具）
   - **Ubuntu 22.04 桌面版固件**（选择带 Desktop 的版本）

2. 打开 **SD_Firmware_Tool**，勾选 `固件升级`

3. 点击 `选择固件`，选择下载的 Ubuntu 固件

4. 将 SD 卡插入读卡器，连接电脑，选择正确的 USB 设备

5. 点击 `开始创建`，等待完成

6. 将 SD 卡插入开发板，上电开机，系统会**自动升级**

7. 升级完成后，取出 SD 卡，开发板自动重启进入 Ubuntu 桌面系统

> ⚠️ **注意**：建议使用 **32GB 及以下容量** 的 SD 卡

## 5. 配置 WiFi 网络

### 5.1 图形界面配置（推荐）

如果连接了显示器：
1. 点击右上角的网络图标
2. 选择你的 WiFi 网络
3. 输入密码连接

### 5.2 命令行配置

```bash
# 查看网络接口
ip link show

# 扫描 WiFi
sudo nmcli device wifi list

# 连接 WiFi（替换为你的 WiFi 名称和密码）
sudo nmcli device wifi connect "你的WiFi名称" password "你的WiFi密码"

# 查看连接状态
nmcli connection show

# 查看 IP 地址
ip addr show wlan0
```

### 5.3 设置静态 IP（可选）

为了方便 SSH 连接，建议设置静态 IP：

```bash
# 编辑网络配置
sudo nmcli connection modify "你的WiFi名称" \
    ipv4.addresses "192.168.1.100/24" \
    ipv4.gateway "192.168.1.1" \
    ipv4.dns "8.8.8.8" \
    ipv4.method manual

# 重启网络
sudo nmcli connection down "你的WiFi名称"
sudo nmcli connection up "你的WiFi名称"
```

### 5.4 获取设备 IP 地址

```bash
# 方法1：查看 IP
ip addr show | grep inet

# 方法2：使用 hostname
hostname -I

# 输出示例：192.168.1.100
```

**记下这个 IP 地址**，后续 SSH 连接需要用到。

## 6. SSH 远程连接

### 6.1 确保 SSH 服务已启动

在开发板上执行：

```bash
# 检查 SSH 服务状态
sudo systemctl status ssh

# 如果未启动，则启动
sudo systemctl start ssh

# 设置开机自启
sudo systemctl enable ssh
```

### 6.2 Windows 连接方法

**方法一：使用 MobaXterm（推荐）**

1. 打开 MobaXterm
2. 点击 "Session" → "SSH"
3. 输入：
   - Remote host: `192.168.1.100`（你的开发板 IP）
   - Username: `firefly`
4. 点击 OK，输入密码 `firefly`

**方法二：使用 PowerShell**

```powershell
ssh firefly@192.168.1.100
```

### 6.3 Mac/Linux 连接方法

打开终端，执行：

```bash
ssh firefly@192.168.1.100
```

### 6.4 配置 SSH 免密登录（推荐）

在你的电脑上：

```bash
# 生成 SSH 密钥（如果还没有）
ssh-keygen -t rsa -b 4096

# 复制公钥到开发板
ssh-copy-id firefly@192.168.1.100

# 之后就可以免密登录了
ssh firefly@192.168.1.100
```

## 7. VSCode 远程开发

### 7.1 安装 Remote-SSH 插件

1. 打开 VSCode
2. 点击左侧扩展图标（或按 `Ctrl+Shift+X`）
3. 搜索 **Remote - SSH**
4. 点击安装

### 7.2 配置 SSH 连接

1. 按 `F1` 打开命令面板
2. 输入 `Remote-SSH: Add New SSH Host`
3. 输入连接命令：
   ```
   ssh firefly@192.168.1.100//这里是你设备的ip，电脑和设备需要在同一内网下
   ```
4. 选择保存到配置文件

### 7.3 连接到开发板

1. 按 `F1`，选择 `Remote-SSH: Connect to Host`
2. 选择 `192.168.1.100`
3. 首次连接选择 Linux 系统
4. 输入密码 `firefly`
5. 等待 VSCode Server 安装完成

### 7.4 打开项目文件夹

连接成功后：
1. 点击 "打开文件夹"
2. 选择你的项目目录，如 `/home/firefly/workspace`
3. 开始愉快地写代码！

### 7.5 推荐安装的 VSCode 插件

在远程连接后安装以下插件：

| 插件 | 用途 |
|------|------|
| C/C++ | C/C++ 语言支持 |
| CMake Tools | CMake 项目支持 |
| Python | Python 开发 |
| GitLens | Git 增强 |

## 8. RKNN 开发环境配置

### 8.1 RKNN 简介

**RKNN** (Rockchip Neural Network) 是瑞芯微为 RK3588 NPU 提供的深度学习推理框架。

架构组成：
- **RKNN-Toolkit2**：模型转换工具（在 PC 上运行）
- **RKNN Runtime**：推理运行时（在开发板上运行）

### 8.2 检查 NPU 驱动

```bash
# 检查 NPU 驱动版本
cat /sys/kernel/debug/rknpu/version
# 输出示例：RKNPU driver: v0.9.2

# 检查 NPU 设备
ls /dev/dri/
# 应该能看到 renderD128 等设备
```

### 8.3 下载 RKNN 官方例程

```bash
# 创建工作目录
mkdir -p ~/workspace
cd ~/workspace

# 克隆 RKNN Model Zoo（官方示例仓库）
git clone https://github.com/airockchip/rknn_model_zoo.git

# 克隆 RKNPU2（运行时库和示例）
git clone https://github.com/rockchip-linux/rknpu2.git
```

### 8.4 安装依赖

```bash
# 安装编译工具
sudo apt install -y build-essential cmake

# 安装 OpenCV
sudo apt install -y libopencv-dev

# 安装 Python 依赖（可选，用于 RKNN-Toolkit2）
sudo apt install -y python3-pip python3-numpy python3-opencv
```

### 8.5 设置环境变量

```bash
# 编辑 bashrc
nano ~/.bashrc

# 添加以下内容（在文件末尾）
export RKNN_PATH=~/workspace/rknpu2
export LD_LIBRARY_PATH=$RKNN_PATH/runtime/Linux/librknn_api/aarch64:$LD_LIBRARY_PATH

# 保存退出（Ctrl+O, Enter, Ctrl+X）

# 使配置生效
source ~/.bashrc
```

## 9. 运行 RKNN 官方例程

### 9.1 例程概览

RKNN Model Zoo 提供了丰富的示例：

| 示例 | 功能 | 目录 |
|------|------|------|
| YOLO | 目标检测 | `examples/yolov5` |
| RetinaFace | 人脸检测 | `examples/retinaface` |
| MobileNet | 图像分类 | `examples/mobilenet` |
| PPOCR | 文字识别 | `examples/ppocr` |

### 9.2 运行 YOLOv5 目标检测示例

```bash
# 进入示例目录
cd ~/workspace/rknn_model_zoo/examples/yolov5/cpp

# 查看目录结构
ls
# CMakeLists.txt  include  model  src

# 下载预转换的 RKNN 模型
cd model
# 按照 README.md 说明下载模型
# 或从 Firefly 资料包获取

# 返回编译
cd ..
mkdir build && cd build

# 编译
cmake .. -DTARGET_SOC=rk3588
make -j4

# 运行
./rknn_yolov5_demo ../model/yolov5s.rknn ../model/test.jpg
```

### 9.3 运行 RetinaFace 人脸检测示例

```bash
# 进入示例目录
cd ~/workspace/rknn_model_zoo/examples/retinaface/cpp

# 编译
mkdir build && cd build
cmake .. -DTARGET_SOC=rk3588
make -j4

# 运行（使用测试图片）
./rknn_retinaface_demo ../model/retinaface.rknn ../model/test.jpg

# 运行（使用摄像头）
./rknn_retinaface_demo ../model/retinaface.rknn /dev/video0
```

### 9.4 查看摄像头设备

```bash
# 列出视频设备
ls /dev/video*

# 查看设备详情
v4l2-ctl --list-devices

# USB 摄像头通常是较大的编号
# 如 /dev/video21
```

### 9.5 运行摄像头实时检测

```bash
# 以 YOLOv5 为例，运行实时检测
./rknn_yolov5_demo ../model/yolov5s.rknn /dev/video21

# 按 'q' 退出
```

## 10. 常见问题

### Q1: SD 卡无法启动系统

**可能原因**：
- SD 卡质量差或损坏
- 镜像烧录不完整
- 启动方式设置错误

**解决方案**：
1. 更换高质量 SD 卡（推荐三星/闪迪）
2. 重新烧录，确保校验通过
3. 检查开发板启动开关设置

### Q2: 无法连接 WiFi

**解决方案**：

```bash
# 检查 WiFi 是否被禁用
rfkill list all

# 如果被禁用，解除
sudo rfkill unblock wifi

# 重启网络管理器
sudo systemctl restart NetworkManager
```

### Q3: SSH 连接被拒绝

**解决方案**：

```bash
# 在开发板上检查 SSH 服务
sudo systemctl status ssh

# 检查防火墙
sudo ufw status

# 如果开启了防火墙，允许 SSH
sudo ufw allow ssh
```

### Q4: VSCode 远程连接失败

**解决方案**：
1. 确保 SSH 可以正常连接
2. 检查开发板磁盘空间（VSCode Server 需要约 200MB）
3. 删除旧的 VSCode Server：
   ```bash
   rm -rf ~/.vscode-server
   ```

### Q5: NPU 模型加载失败

**可能原因**：
- 模型版本不匹配
- 运行时库版本不对
- 权限不足

**解决方案**：

```bash
# 检查 RKNN 版本兼容性
cat /sys/kernel/debug/rknpu/version

# 确保库路径正确
echo $LD_LIBRARY_PATH

# 检查模型文件权限
ls -la model.rknn
```

### Q6: 编译时找不到 OpenCV

**解决方案**：

```bash
# 安装 OpenCV
sudo apt install libopencv-dev

# 检查安装
pkg-config --modversion opencv4
```
