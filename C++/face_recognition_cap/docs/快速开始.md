## 系统要求

### 硬件要求
- **开发板**: Firefly EC-A3588Q (RK3588)
- **NPU**: RKNPU2 (支持 RKNN 模型)
- **摄像头**: USB 摄像头或 MIPI 摄像头
- **内存**: 至少 2GB RAM

### 软件依赖
- **操作系统**: Ubuntu 22.04 (ARM64)
- **编译器**: GCC 7.5+ (支持 C++11)
- **CMake**: 3.4.1+
- **OpenCV**: 4.x
- **RKNN Runtime**: librknnrt.so (已包含在项目中)
- **RGA**: librga.so (硬件加速库，已包含)

### 安装依赖

```bash
sudo apt update
sudo apt install cmake build-essential
sudo apt install libopencv-dev
```

## 编译项目

### 1. 进入项目目录

```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition_cap
```

### 2. 执行编译脚本

```bash
bash build.sh
```

编译过程会：
1. 创建 `build` 目录
2. 使用 CMake 生成 Makefile
3. 编译所有源文件
4. 将可执行文件和依赖库安装到 `install/face_recognition_cap/` 目录

### 3. 验证编译结果

```bash
ls -lh install/face_recognition_cap/face_recognition_cap
```

应该看到一个约 300KB 的可执行文件。

## 准备特征库

在运行人脸识别之前，需要先生成人脸特征库。

### 1. 准备人脸图片

将待识别人员的人脸照片放入 `data/img/` 目录，命名格式：`姓名_编号.jpg`

```
data/img/
├── 张三_1.jpg
├── 张三_2.jpg
├── 李四_1.jpg
└── 王五_1.jpg
```

### 2. 生成特征库

使用 `face_recognition` 工具生成特征库：

```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition
bash build.sh
cd install/face_recognition
./face_recognition data/model/retinaface.rknn data/model/w600k_mbf.rknn data/img/
```

生成的特征文件会保存在 `data/face_feature_lib/` 目录。

### 3. 复制特征库

将生成的特征库复制到 `face_recognition_cap` 项目：

```bash
cp -r data/face_feature_lib /home/firefly/open_project/edge2-npu/C++/face_recognition_cap/install/face_recognition_cap/data/
```

## 运行程序

### 1. 查看摄像头设备

对于 USB 摄像头，先查看设备编号：

```bash
lsusb
```

输出示例：
```
Bus 001 Device 021: ID 046d:0825 Logitech, Inc. Webcam C270
```

设备编号为 `21`。

### 2. 运行人脸识别

```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition_cap/install/face_recognition_cap
./face_recognition_cap data/model/retinaface.rknn data/model/w600k_mbf.rknn usb 21
```

**参数说明**:
- `data/model/retinaface.rknn`: RetinaFace 人脸检测模型
- `data/model/w600k_mbf.rknn`: FaceNet 特征提取模型 (512维)
- `usb`: 摄像头类型 (`usb` 或 `mipi`)
- `21`: 设备编号

### 3. 查看运行效果

程序启动后会显示：
- 实时视频画面
- 人脸检测框
- 识别结果（人名或 "stranger"）
- FPS 和性能统计

按 `Ctrl+C` 退出程序。

## 常见问题

### Q1: 编译失败，提示找不到 OpenCV

**解决方法**:
```bash
sudo apt install libopencv-dev
```

### Q2: 运行时提示 "Feature library doesn't exist"

**解决方法**:
确保已生成特征库并复制到正确位置：
```bash
ls install/face_recognition_cap/data/face_feature_lib/
```

### Q3: 摄像头无法打开

**解决方法**:
1. 检查摄像头是否连接：`lsusb`
2. 检查设备权限：`sudo chmod 666 /dev/video*`
3. 尝试不同的设备编号

### Q4: FPS 很低（< 10）

**可能原因**:
- 摄像头分辨率过高（建议 1280x720）
- 特征库过大（建议 < 100 人）
- 系统负载过高

**优化建议**:
- 降低摄像头分辨率
- 减少特征库人数
- 关闭其他占用 NPU 的程序

### Q5: 识别准确率低

**解决方法**:
1. 调整识别阈值（默认 0.5）
2. 使用高质量的人脸照片生成特征库
3. 确保光照条件良好

## 性能参考

在 Firefly Edge2 (RK3588) 上的性能表现：

| 配置 | FPS | 延迟 |
|------|-----|------|
| 1280x720, 1人 | 60-73 | 13-16ms |
| 1280x720, 3人 | 35-45 | 22-28ms |
| 1920x1080, 1人 | 40-50 | 20-25ms |

**优化特性**:
- ✅ 三线程架构（预处理、渲染、主线程）
- ✅ 异步 USB 摄像头读取
- ✅ RGA 硬件加速图像处理
- ✅ NPU 加速模型推理
