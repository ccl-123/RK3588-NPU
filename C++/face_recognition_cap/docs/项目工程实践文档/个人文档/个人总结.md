## 3. 技术收获

### 3.1 嵌入式 AI 技术

（1）**RKNN 模型部署**

掌握了 ONNX 模型转 RKNN 的完整流程，包括模型量化、校准数据集准备、精度验证等。理解了 INT8 量化对模型精度的影响，以及如何通过选择合适的校准数据集来降低精度损失。

（2）**YOLOv8 后处理**

深入理解了 YOLOv8 的 DFL（Distribution Focal Loss）边界框回归机制，实现了 Softmax 解码算法。掌握了 NMS（非极大值抑制）算法的原理和高效实现。

（3）**人脸识别算法**

学习了基于深度学习的人脸识别流程：检测、对齐、特征提取、比对。理解了 ArcFace 损失函数的原理，掌握了余弦相似度计算和阈值选择方法。

### 3.2 性能优化技术

（1）**多线程编程**

掌握了 C++ 多线程编程，包括线程创建、互斥锁、条件变量、原子操作等。理解了生产者-消费者模型在图像处理流水线中的应用。

（2）**硬件加速**

学习了 RGA（Rockchip Graphics Accelerator）的使用，实现了图像缩放、格式转换的硬件加速。理解了 NPU 推理的异步执行机制。

（3）**性能分析**

掌握了性能瓶颈分析方法，通过计时和日志定位性能问题。学会了针对性优化，将整体 FPS 提升了 272%。

### 3.3 软件工程技术

（1）**Qt GUI 开发**

掌握了 Qt5 Widgets 开发，包括信号槽机制、布局管理、QSS 样式表、多线程与 GUI 交互等。

（2）**数据库开发**

学习了 SQLite 数据库的使用，包括表设计、SQL 语句编写、事务处理等。

（3）**版本控制**

熟练使用 Git 进行版本管理，包括分支管理、合并、冲突解决等。

## 4. 遇到的困难与解决

### 4.1 技术难题

**难题1：YOLOv8 后处理实现**

问题描述：初次部署 YOLOv8-face 模型时，检测框位置完全错误，屏幕上满是检测框。

解决过程：

（1）分析 RKNN 模型输出格式，发现 RKOPT 版本有 4 个输出 tensor

（2）阅读 rknn_model_zoo 参考代码，理解 DFL 解码流程

（3）实现 Softmax 解码和边界框计算

（4）调试坐标变换，处理 letterbox 缩放的逆变换

经验总结：部署新模型前，需要充分了解其输出格式和后处理流程。

**难题2：近距离检测失效**

问题描述：人脸靠近摄像头时检测不到，远离反而能检测到。

解决过程：

（1）对比测试分支和主分支的配置差异

（2）发现置信度阈值设置不同（0.7 vs 0.5）

（3）调整阈值后问题解决

经验总结：调试时要善用对比法，找出工作版本和问题版本的差异。

**难题3：性能优化**

问题描述：初始 FPS 仅 14.2，无法满足实时性要求。

解决过程：

（1）添加计时日志，定位性能瓶颈（摄像头读取占 31ms）

（2）实现异步读取线程 + 双缓冲机制

（3）使用 RGA 硬件加速图像预处理

（4）优化后 FPS 达到 56.6

经验总结：性能优化要基于数据，先定位瓶颈再针对性优化。

### 4.2 工程问题

**问题1：模型量化精度下降**

原因：使用 COCO 数据集校准人脸检测模型

解决：改用 WIDER FACE 人脸数据集进行量化校准

**问题2：UI 布局抖动**

原因：用户名长度变化导致布局重新计算

解决：使用固定宽度容器，限制标签最大宽度

## 5. 经验教训

### 5.1 技术层面

（1）**充分调研再动手**

在开始编码前，应该充分了解所用技术的特点和限制。例如 YOLOv8 的 RKOPT 格式与原始格式输出不同，如果不了解就会走弯路。

（2）**日志是调试利器**

在关键位置添加日志输出，可以快速定位问题。spdlog 库提供了高性能的日志功能，应该善于利用。

（3）**参考优秀代码**

rknn_model_zoo 提供了大量参考实现，阅读这些代码可以学习最佳实践，避免重复造轮子。

（4）**测试驱动开发**

每实现一个功能就进行测试，可以及早发现问题。不要等到所有功能开发完再测试。

### 5.2 项目管理层面

（1）**时间预估要保守**

实际开发时间往往是预估的 1.5-2 倍，特别是调试和优化阶段。制定计划时要预留缓冲时间。

（2）**文档要及时编写**

边开发边写文档，可以避免遗忘细节。如果等项目结束再写，很多实现细节已经模糊。

（3）**版本控制要规范**

使用有意义的提交信息，方便后续追溯。重要功能使用分支开发，避免影响主分支稳定性。
