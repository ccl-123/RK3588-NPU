## 2 用途

### 2.1 功能

本系统提供以下功能：

1. **实时人脸检测与识别**
   - 实时采集摄像头视频流，检测画面中的人脸
   - 提取人脸特征，与已注册用户进行比对识别
   - 识别准确率 ≥ 99%，支持同时检测多张人脸
   - 检测距离：0.3 米 - 3 米

2. **自动考勤记录**
   - 12:00 前识别自动记录为签到，12:00 后记录为签退
   - 防重复签到功能（可配置冷却时间，默认 5 分钟）
   - 考勤记录持久化存储，支持历史查询

3. **用户管理**
   - 用户注册：输入姓名，采集人脸照片
   - 用户删除：删除用户及关联的人脸特征
   - 支持多角度人脸采集，提高识别率

4. **考勤查询与导出**
   - 按日期范围查询考勤记录
   - 按用户查询个人考勤记录
   - 支持导出考勤数据

5. **系统设置**
   - 识别阈值调整（0.3 - 0.9）
   - 深色/浅色主题切换
   - 语音播报开关和音量调节
   - 天气城市配置

6. **辅助功能**
   - 语音播报：签到成功、签退成功、陌生人提示
   - 天气显示：实时温度、天气状况、空气质量
   - 每日一句：随机励志语句显示

### 2.2 性能

#### 2.2.1 精度

| 项目 | 精度要求 |
|------|----------|
| 人脸检测率 | ≥ 98%（正常光照、正脸） |
| 人脸识别准确率 | ≥ 99%（已注册用户） |
| 误识率 | < 0.1% |
| 陌生人拒识率 | ≥ 99% |
| 特征向量维度 | 512 维（float32） |

#### 2.2.2 时间特性

| 项目 | 时间要求 |
|------|----------|
| 视频帧率 | ≥ 30 FPS |
| 人脸检测延迟 | < 30 ms |
| 人脸识别延迟 | < 50 ms |
| 界面响应时间 | < 100 ms |
| 系统启动时间 | < 5 秒 |

#### 2.2.3 灵活性

1. **识别阈值可调**：用户可根据实际环境调整识别灵敏度
2. **多摄像头支持**：支持 USB 和 MIPI 两种摄像头接口
3. **主题可切换**：支持深色和浅色两种界面主题
4. **配置持久化**：所有设置自动保存，重启后保持

### 2.3 安全保密

1. **数据本地存储**：人脸特征和考勤记录存储在本地 SQLite 数据库，不上传云端
2. **特征向量存储**：仅存储 512 维特征向量，不保存原始人脸照片
3. **离线运行**：核心功能完全离线可用，无需网络连接
4. **隐私合规**：遵循《个人信息保护法》和《人脸识别数据安全要求》

## 3 运行环境

### 3.1 硬设备

**最低配置：**

| 类别 | 配置要求 |
|------|----------|
| 处理器 | RK3588 系列芯片（含 NPU） |
| 内存 | ≥ 4 GB |
| 存储 | ≥ 4 GB 可用空间 |
| 摄像头 | USB 摄像头，分辨率 ≥ 720P |
| 显示器 | 支持 HDMI 输出 |

**推荐配置：**

| 类别 | 配置要求 |
|------|----------|
| 处理器 | EC-A3588Q（8核 CPU + 6 TOPS NPU） |
| 内存 | 8 GB |
| 存储 | 16 GB |
| 摄像头 | 罗技 C720 或更高规格（1080P） |
| 显示器 | 24 寸 1080P 显示器 |

### 3.2 支持软件

| 类别 | 软件名称 | 版本要求 |
|------|----------|----------|
| 操作系统 | Ubuntu | 22.04 LTS |
| NPU 运行时 | RKNN Runtime | 2.3.0 |
| 图像处理库 | OpenCV | 4.5+ |
| GUI 框架 | Qt | 5.15 |
| 数据库 | SQLite | 3.x |

### 3.3 数据结构

系统使用 SQLite 数据库存储数据，数据库文件位于：`data/attendance.db`

主要数据表：

| 表名 | 用途 |
|------|------|
| users | 存储用户基本信息 |
| face_features | 存储人脸特征向量 |
| attendance_records | 存储考勤记录 |

## 4 使用过程

### 4.1 安装与初始化

#### 4.1.1 系统安装

**步骤 1：准备环境**

```bash
# 安装依赖库
sudo apt update
sudo apt install libopencv-dev qt5-default libsqlite3-dev
```

**步骤 2：复制程序文件**

将程序目录复制到目标位置：

```bash
cp -r face_recognition_cap /home/user/
cd /home/user/face_recognition_cap
```

**步骤 3：编译程序（如需重新编译）**

```bash
mkdir build && cd build
cmake ..
make -j4
```

#### 4.1.2 启动程序

**GUI 模式：**

```bash
cd /home/user/face_recognition_cap
./build/face_recognition_gui
```

#### 4.1.3 初始化验证

程序启动后，检查以下内容确认初始化成功：

1. 视频画面正常显示
2. 左上角显示 FPS 数值（应 ≥ 30）
3. 右下角显示天气信息（需联网）
4. 无错误提示弹窗

### 4.2 输入

#### 4.2.1 输入数据的现实背景

| 项目 | 说明 |
|------|------|
| 情况 | 用户站在摄像头前进行人脸识别签到/签退 |
| 频度 | 每天上下班各一次，或根据考勤规则多次 |
| 来源 | USB 摄像头实时采集 |
| 输入媒体 | 视频流（1280×720，30FPS） |
| 限制 | 需正面面对摄像头，距离 0.3-3 米 |
| 质量管理 | 自动检测人脸质量，光线不足时提示 |

#### 4.2.2 输入格式

**人脸图像输入要求：**

| 项目 | 要求 |
|------|------|
| 分辨率 | ≥ 720P（1280×720） |
| 帧率 | ≥ 30 FPS |
| 格式 | BGR 彩色图像 |
| 人脸大小 | 图像中人脸宽度 ≥ 50 像素 |
| 姿态 | 正脸或小角度侧脸（≤ 30°） |
| 遮挡 | 不佩戴墨镜、口罩 |

**用户注册输入：**

| 项目 | 要求 |
|------|------|
| 姓名 | 1-20 个字符 |
| 人脸照片 | 建议采集 3 张不同角度 |

#### 4.2.3 输入举例

**场景 1：日常签到**

1. 用户站在摄像头前 0.5-2 米处
2. 正面面对摄像头
3. 系统自动检测人脸并识别
4. 连续 5 帧识别成功后自动签到
5. 语音播报"签到成功"

**场景 2：用户注册**

1. 点击"用户管理"页面
2. 点击"添加用户"按钮
3. 输入用户姓名："张三"
4. 点击"采集照片"，正面面对摄像头
5. 采集 3 张照片后点击"保存"

### 4.5 出错处理和恢复

#### 4.5.1 常见错误及处理

| 错误现象 | 可能原因 | 处理方法 |
|----------|----------|----------|
| 视频画面黑屏 | 摄像头未连接或被占用 | 检查摄像头连接，重启程序 |
| 检测不到人脸 | 光线太暗或距离太远 | 增加光照，靠近摄像头 |
| 识别不出已注册用户 | 阈值设置过高 | 降低识别阈值 |
| 程序启动失败 | 模型文件缺失 | 检查 data/model/ 目录下的模型文件 |
| 考勤记录未保存 | 数据库文件损坏 | 备份后删除 data/attendance.db，重新初始化 |

#### 4.5.2 系统恢复

**重启程序：**

```bash
# 强制结束程序
killall face_recognition_gui

# 重新启动
./build/face_recognition_gui
```

**重置配置：**

```bash
# 删除配置文件，恢复默认设置
rm ~/.config/FaceRecognition/settings.ini
```

**重建数据库：**

```bash
# 备份原数据库
mv data/attendance.db data/attendance.db.bak

# 程序启动时会自动创建新数据库
./build/face_recognition_gui
```
