## 1 引言

### 1.1 编写目的

本测试说明书旨在记录"基于人脸检测与识别的智能考勤系统"的测试过程、测试结果及分析结论。通过系统性的功能测试和性能测试，验证系统是否满足设计需求，发现潜在缺陷并提出改进建议。

本文档的预期读者包括：项目开发人员、指导教师、项目验收人员。

### 1.2 背景

1. **被测试软件名称**：基于人脸检测与识别的智能考勤系统（FaceRecognition Attendance System）
2. **任务提出者**：物联网工程专业项目工程实践课程
3. **开发者**：陈亮（22物联网工程1班，学号：20220070120）
4. **目标用户**：企业、学校等需要考勤管理的机构
5. **运行平台**：EC-A3588Q 开发板（RK3588 芯片，Ubuntu 22.04）

**测试环境与实际运行环境的差异**：
- 测试环境使用 USB 摄像头（罗技 C720），实际部署可能使用 MIPI 摄像头
- 测试用户数量为 10 人，实际部署可支持 1000+ 人
- 测试环境光照条件较为理想，实际环境可能存在逆光、暗光等情况

### 1.3 定义

- **RKNN**：Rockchip Neural Network，瑞芯微神经网络模型格式
- **NPU**：Neural Processing Unit，神经网络处理单元
- **FPS**：Frames Per Second，每秒帧数
- **NMS**：Non-Maximum Suppression，非极大值抑制
- **YOLOv8-face**：基于 YOLOv8 的人脸检测模型
- **MobileFaceNet**：轻量级人脸特征提取模型
- **RGA**：Rockchip Graphics Accelerator，瑞芯微 2D 图形加速器

## 2 测试概要

本系统共进行了 6 类测试，测试内容如下：

1. **TEST-001 人脸检测功能测试**：验证 YOLOv8-face 模型的人脸检测能力，包括单人/多人检测、不同角度检测
2. **TEST-002 人脸识别功能测试**：验证 MobileFaceNet 的人脸识别准确率，包括注册用户识别、陌生人检测
3. **TEST-003 考勤功能测试**：验证签到/签退逻辑、防重复签到、考勤记录保存
4. **TEST-004 用户管理功能测试**：验证用户注册、删除、人脸采集功能
5. **TEST-005 GUI 界面测试**：验证界面交互、主题切换、数据显示
6. **TEST-006 性能测试**：验证实时帧率、检测延迟、系统稳定性

**与测试计划的差异**：原计划进行压力测试（100 人同时识别），因硬件条件限制改为 10 人规模测试。

## 3 测试结果及发现

### 3.1 TEST-001 人脸检测功能测试

**测试内容**：使用 YOLOv8-face 模型进行人脸检测

**测试结果**：

1. **单人正脸检测**：检测率 100%，关键点定位准确
2. **单人侧脸检测（45°）**：检测率 98%，偶有漏检
3. **多人检测（3人）**：检测率 100%，所有人脸均能检出
4. **远距离检测（3米）**：检测率 95%，小人脸检测稳定
5. **近距离检测（0.3米）**：检测率 100%，调整阈值后正常

**发现的问题**：
- 初始置信度阈值设置过高（0.7），导致近距离人脸漏检
- 已修复：将阈值调整为 0.5

### 3.2 TEST-002 人脸识别功能测试

**测试内容**：使用 MobileFaceNet 进行人脸特征比对

**测试结果**：

1. **注册用户识别**：准确率 99.5%（200 次测试，199 次正确）
2. **陌生人检测**：准确率 100%（50 次测试，均正确识别为陌生人）
3. **相似人脸区分**：准确率 98%（双胞胎测试未进行）
4. **不同光照条件**：正常光照 99%，弱光 92%，强逆光 85%

**发现的问题**：
- 弱光环境下识别率下降约 7%
- 建议：后续版本添加图像增强预处理

### 3.3 TEST-003 考勤功能测试

**测试内容**：验证考勤业务逻辑

**测试结果**：

1. **签到功能**：12:00 前识别自动记录为签到，功能正常
2. **签退功能**：12:00 后识别自动记录为签退，功能正常
3. **防重复签到**：5 分钟内重复识别不重复记录，功能正常
4. **考勤记录保存**：SQLite 数据库记录完整，可查询
5. **考勤导出**：支持按日期导出考勤表，功能正常

**发现的问题**：
- 时区问题导致重复签到判断失效（已修复，SQL 添加 localtime 修饰符）

### 3.4 TEST-004 用户管理功能测试

**测试内容**：验证用户注册和管理功能

**测试结果**：

1. **用户注册**：支持输入姓名、采集人脸照片，功能正常
2. **多角度采集**：支持采集多张照片提高识别率
3. **用户删除**：删除用户后特征库同步更新
4. **用户列表**：正确显示所有注册用户

**发现的问题**：
- 新注册用户需重启应用才能识别（特征库未热更新）
- 状态：待改进

### 3.5 TEST-005 GUI 界面测试

**测试内容**：验证图形界面功能

**测试结果**：

1. **实时视频显示**：流畅，无卡顿
2. **检测框绘制**：准确跟随人脸移动
3. **主题切换**：深色/浅色主题切换正常
4. **考勤查询**：按日期/用户查询功能正常
5. **设置保存**：阈值、音频等设置持久化正常

**发现的问题**：
- 用户名过长时显示截断（已修复，调整标签宽度）
- 签到状态标签导致布局抖动（已修复，使用固定宽度容器）

### 3.6 TEST-006 性能测试

**测试内容**：验证系统性能指标

**测试结果**：

1. **实时帧率**：平均 35 FPS，峰值 56.6 FPS
2. **检测延迟**：单帧处理 < 30ms
3. **启动时间**：约 3 秒（含模型加载）
4. **内存占用**：约 500MB
5. **长时间运行**：连续运行 8 小时无崩溃

**发现的问题**：
- RGA 调试日志影响终端输出（不影响功能）

## 4 对软件功能的结论

### 4.1 人脸检测功能（TEST-001）

#### 4.1.1 能力

- 支持实时多人脸检测，单帧最多检测 10+ 张人脸
- 输出 5 点关键点（左眼、右眼、鼻尖、左嘴角、右嘴角）
- 支持 0.3 米至 3 米检测距离
- 检测帧率 > 30 FPS

#### 4.1.2 限制

- 侧脸角度超过 60° 时检测率下降
- 遮挡面积超过 50% 时无法检测
- 极端光照条件下检测率下降

### 4.2 人脸识别功能（TEST-002）

#### 4.2.1 能力

- 512 维特征向量提取，识别准确率 > 99%
- 支持余弦相似度和欧氏距离两种比对方式
- 陌生人检测准确率 100%
- 特征比对延迟 < 5ms

#### 4.2.2 限制

- 弱光环境识别率下降约 7%
- 佩戴墨镜/口罩时无法识别
- 不支持活体检测，存在照片攻击风险

### 4.3 考勤管理功能（TEST-003）

#### 4.3.1 能力

- 智能签到/签退判断（12:00 分界）
- 可配置的防重复签到间隔
- 考勤记录持久化存储
- 支持考勤数据导出

#### 4.3.2 限制

- 不支持跨天考勤（如夜班）
- 不支持多考勤规则（如上午班、下午班）

### 4.4 用户管理功能（TEST-004）

#### 4.4.1 能力

- 支持用户注册、删除、查询
- 支持多角度人脸采集
- 用户数据持久化存储

#### 4.4.2 限制

- 不支持用户信息编辑
- 新用户注册后需重启生效

### 4.5 GUI 界面功能（TEST-005）

#### 4.5.1 能力

- 现代化 Qt5 界面，支持深色/浅色主题
- 实时视频流畅显示
- 天气、时间、每日一句等辅助信息
- 语音播报功能

#### 4.5.2 限制

- 不支持全屏模式
- 不支持多语言切换

## 5 分析摘要

### 5.1 能力

经测试验证，本系统具备以下能力：

1. **高效的人脸检测**：基于 YOLOv8-face 模型，检测速度快（< 30ms），准确率高（> 98%）
2. **准确的人脸识别**：基于 MobileFaceNet 模型，识别准确率 > 99%，支持 1000+ 人特征库
3. **完整的考勤功能**：自动签到/签退、防重复、记录查询、数据导出
4. **友好的用户界面**：现代化 GUI、主题切换、语音播报
5. **优秀的实时性能**：30+ FPS 实时处理，充分利用 NPU 硬件加速

### 5.2 缺陷和限制

1. **活体检测缺失**：无法防范照片/视频攻击，安全性不足
2. **光照适应性差**：弱光、逆光环境下性能下降
3. **特征库不支持热更新**：新用户需重启应用
4. **考勤规则单一**：仅支持简单的上下班签到模式

**累积影响**：上述缺陷不影响系统在理想环境下的正常使用，但限制了系统在复杂场景中的适用性。

### 5.3 建议

1. **活体检测**
   - 修改方法：集成 Silent Face Anti-Spoofing 模型
   - 紧迫程度：高
   - 预计工作量：2 周
   - 负责人：待定

2. **图像增强**
   - 修改方法：添加 CLAHE 自适应直方图均衡化预处理
   - 紧迫程度：中
   - 预计工作量：3 天
   - 负责人：待定

3. **特征库热更新**
   - 修改方法：实现动态加载机制，监听数据库变化
   - 紧迫程度：中
   - 预计工作量：1 周
   - 负责人：待定

4. **多考勤规则**
   - 修改方法：扩展数据库表结构，支持多时段配置
   - 紧迫程度：低
   - 预计工作量：1 周
   - 负责人：待定

### 5.4 评价

本系统已基本达到预定开发目标：

1. ✅ 实现基于深度学习的人脸检测和识别
2. ✅ 实现自动考勤记录和查询
3. ✅ 实现友好的图形用户界面
4. ✅ 充分利用 RK3588 NPU 硬件加速
5. ✅ 实时性能满足要求（30+ FPS）

**结论**：系统可交付使用，建议在实际部署前补充活体检测功能以提升安全性。
