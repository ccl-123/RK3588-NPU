# 快速开始

本文档指导用户如何在 RK3588 环境下快速启动人脸识别考勤系统。

## 环境要求

- **硬件**: RK3588 开发板，1080P USB 摄像头。
- **软件**: Ubuntu 22.04 预装 OpenCV 与 Qt5。

## 启动步骤

### 1. 安装基础依赖
```bash
sudo apt update
sudo apt install cmake build-essential libopencv-dev qt5-default libsqlite3-dev
```

### 2. 构建项目
```bash
cd /home/firefly/open_project/edge2-npu/C++/face_recognition_cap
./build.sh
```

### 3. 初始化数据库
系统首次运行前需初始化数据库：
```bash
cd install/face_recognition_cap
./db_tool init data/database/face_recognition.db
```

### 4. 启动 GUI 界面
```bash
# 启动现代化图形界面
./face_recognition_cap_gui
```

## 核心操作指南

1.  **打开摄像头**: 首次启动后，点击左侧导航栏的 **“实时画面”**，系统会自动尝试连接 /dev/video0。
2.  **录入人脸**: 
    - 切换到 **“用户管理”** 页面。
    - 点击 **“注册人脸”**。
    - 站在摄像头前，根据提示采集 3-5 张照片。
    - 填写姓名与部门，点击提交。
3.  **开始识别**:
    - 切换回 **"实时画面"**。
    - 当系统检测到已注册人员超过 1 秒（默认配置）时，会发出语音提示并自动记录考勤。

4.  **AI 智能分析** (新功能):
    - 点击左侧导航栏的 **"智能看板"**。
    - 点击底部输入框左侧按钮切换 **云端/本地** 模式。
    - 输入问题如 "今天谁迟到了？" 或 "分析本周考勤"。
    - AI 将自动查询数据并给出分析结果。

## 故障排查

- **摄像头画面黑屏**: 检查 `/dev/video*` 权限，尝试 `sudo chmod 666 /dev/video0`。
- **FPS 过低**: 确认 NPU 驱动版本是否为 2.x 以上。
- **AI 分析无响应**: 本地模式需等待模型加载（约 5-10 秒），状态栏显示"就绪"后再提问。
- **本地 LLM 加载失败**: 检查模型文件路径是否正确，确认 NPU 资源未被占用。
