# 快速开始

> 版本: v2.4
> 更新日期: 2026-04-01

本文档指导你在 RK3588 环境下快速启动系统，并体验当前 AI Agent 能力。

## 环境要求

- RK3588 开发板
- Ubuntu 22.04
- USB 摄像头
- Qt5 / OpenCV / SQLite3 / RKNN / RKLLM 依赖

## 1. 构建

### 板端构建

```bash
cd C++/face_recognition_cap
./device_build.sh
```

### 交叉编译

```bash
cd C++/face_recognition_cap
./cross_build.sh --build
```

## 2. 初始化数据库

首次运行前建议初始化数据库：

```bash
cd install/face_recognition_cap
./db_tool init data/database/face_recognition.db
```

## 3. 启动 GUI

```bash
./face_recognition_cap_gui
```

## 4. 配置大模型后端

### 本地 RKLLM

```bash
export LOCAL_LLM_MODEL_PATH=/path/to/your_model.rkllm
```

### OpenAI 兼容自定义远端接口

```bash
export LLAMA_CPP_SERVER_URL=http://127.0.0.1:8080
export LLAMA_CPP_SERVER_MODEL=gpt-4o-mini
export LLAMA_CPP_SERVER_API_KEY=sk-your-key
```

说明：

- `LLAMA_CPP_SERVER_URL` 只写基地址
- 代码会自动拼 `/v1/chat/completions`
- 远端模式需要配置该地址后才能使用 OpenAI 兼容后端

## 5. 基础操作

### 人脸注册

1. 进入“用户管理”
2. 点击“注册人脸”
3. 采集 3-5 张有效脸图
4. 填写姓名和部门
5. 提交保存

### 日常打卡

1. 打开“实时画面”
2. 对准摄像头
3. 等待识别结果
4. 系统自动记录签到或签退

### 智能看板

1. 进入“智能看板”
2. 选择本地或远端模式
3. 输入问题

推荐测试问题：

- “今天谁迟到了？”
- “张三这周出勤怎么样？”
- “研发部今天出勤率多少？”
- “本月迟到最多的是谁？”
- “今天谁还没签到？”

## 6. 常见问题

### 摄像头黑屏

- 检查 `/dev/video*`
- 检查设备权限

### 本地模型无法加载

- 检查 `LOCAL_LLM_MODEL_PATH`
- 检查模型文件是否存在
- 检查 NPU 是否被其他程序占用

### 远端模式没有切到自定义接口

- 检查：

```bash
echo "$LLAMA_CPP_SERVER_URL"
```

如果为空，说明环境变量没有导出成功。
