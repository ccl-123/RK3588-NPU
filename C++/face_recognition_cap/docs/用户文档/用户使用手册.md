# 用户使用手册

## 功能概览

人脸识别考勤系统是一款基于 RK3588 NPU 硬件加速的高性能办公应用。

### 主要功能页
1.  **实时画面**: 核心识别页面，包含视频流显示、人脸框追踪、实时考勤状态滚动。
2.  **考勤记录**: 展示今日及历史打卡明细，支持状态筛选。
3.  **用户管理**: 维护公司人员信息，执行人脸特征注册与删除。
4.  **系统设置**: 调节识别阈值、摄像头设备号及 UI 主题切换。

---

## 现代化特性

### 1. 实时资讯看板
在 **“实时画面”** 页面的侧边栏或顶部，系统集成了：
- **天气预报**: 自动获取当地实时天气。
- **新闻热点**: 滚动显示最新头条资讯。
- **节假日提醒**: 自动识别法定工作日与节假日。

### 2. 主题系统
在 **“系统设置”** 或标题栏快捷按钮中，您可以：
- 在 **浅色模式** 与 **深色模式** 之间一键切换。
- 所有 SVG 图标将根据主题色自动适配。

---

## 人脸注册进阶

为获得最佳识别效果，请遵循：
- **采集光线**: 保持环境光线均匀，避免强背光。
- **姿态建议**: 采集时请分别录入：正面、稍微低头、稍微抬头。
- **多人识别**: 系统支持多人同时入镜识别，但在注册时请确保画面中仅有一人。

---

## 考勤规则说明

- **重复打卡屏蔽**: 默认 30 分钟内识别同一人不会产生多次重复记录。
- **考勤判定**: 
  - **签到**: 规定上班时间前。
  - **迟到**: 规定上班时间后。
  - **签退**: 规定下班时间后。
