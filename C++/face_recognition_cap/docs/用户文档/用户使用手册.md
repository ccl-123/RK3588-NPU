# 用户使用手册

> 版本: v2.4
> 更新日期: 2026-04-01

## 页面概览

### 1. 实时画面

用于：

- 实时识别人脸
- 自动打卡
- 查看识别状态与语音提示

### 2. 智能看板

用于：

- 自然语言提问
- 查看流式分析结果
- 在本地 / 远端模式之间切换

### 3. 考勤记录

用于：

- 查看打卡明细
- 按时间或状态筛选

### 4. 用户管理

用于：

- 注册用户
- 管理用户资料
- 维护人脸特征

### 5. 系统设置

用于：

- 调整识别阈值
- 配置摄像头
- 切换主题

## 智能看板使用说明

智能看板是当前系统最主要的升级点。

### 支持的问题类型

#### 全局考勤

- “今天有多少人打卡？”
- “本周迟到情况如何？”

#### 单员工考勤

- “张三这周出勤怎么样？”
- “李四最近一次打卡是什么时候？”

#### 部门考勤

- “研发部今天出勤率多少？”
- “销售部近 30 天异常情况怎么样？”

#### 排名分析

- “本月迟到最多的是谁？”
- “最近 7 天异常最多的前 5 个人是谁？”

#### 缺卡缺勤

- “今天谁还没签到？”
- “谁只签到没签退？”
- “哪些人连续两天没打卡？”

### 模式说明

#### 本地模式

- 依赖 RKLLM 模型
- 数据不出设备
- 适合离线环境

#### 远端模式

- 通过 `LLAMA_CPP_SERVER_URL` 调用 OpenAI 兼容远端接口
- 未配置该变量时，远端模式会提示先配置服务地址

## 人脸注册建议

- 保持光线均匀
- 尽量正脸
- 不遮挡五官
- 建议采集多张不同微小角度的人脸图

## 常见问题

### 为什么 AI 没有返回结果？

可能原因：

- 本地模型未加载
- OpenAI 兼容远端环境变量未配置

### 为什么远端模式没有切到自定义接口？

检查：

```bash
echo "$LLAMA_CPP_SERVER_URL"
echo "$LLAMA_CPP_SERVER_MODEL"
```

### 为什么提问后返回“没有找到用户”？

当前系统支持按：

- `user_id`
- `姓名关键词`

查询单员工工具。如果有重名用户，系统会提示改用更精确条件。
