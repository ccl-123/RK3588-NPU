## 当前用户可见 AI 能力

当前智能看板已经支持：

- 全局考勤问答
- 单员工考勤问答
- 部门考勤问答
- 排名问答
- 缺卡缺勤问答

常见问题示例：

- “今天谁迟到了？”
- “张三这周出勤怎么样？”
- “研发部今天出勤率多少？”
- “本月迟到最多的是谁？”
- “今天谁还没签到？”

## 使用提醒

- 本地模式依赖 RKLLM 模型文件
- 远端模式依赖 OpenAI 兼容接口配置
- 需要配置 `LLAMA_CPP_SERVER_URL` 后才能使用远端模式
