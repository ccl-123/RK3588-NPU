## 📱 系统要求

### 最低配置
- **操作系统**: Windows 10 / Linux
- **内存**: 4GB
- **摄像头**: USB摄像头（720p以上）
- **处理器**: Intel i3 或同等性能

### 推荐配置
- **操作系统**: Windows 11 / Ubuntu 20.04
- **内存**: 8GB
- **摄像头**: USB摄像头（1080p）
- **处理器**: Intel i5 或更高
